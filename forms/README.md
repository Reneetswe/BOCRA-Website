# BOCRA License Application Forms

This directory contains official BOCRA application forms for different license types.

## Form Codes and License Types

| License Type | Form Code | Processing Time |
|-------------|-----------|-----------------|
| Aircraft Radio Licence | AR-001 | 21 business days |
| Amateur Radio Licence | AM-001 | 14 business days |
| Broadcasting Licence | BC-001 | 45 business days |
| Cellular Licence | CL-001 | 60 business days |
| Citizen Band Radio Licence | CB-001 | 7 business days |
| Point-to-Multipoint Licence | PM-001 | 30 business days |
| Point-to-Point Licence | PP-001 | 21 business days |
| Private Radio Communication Licence | PR-001 | 14 business days |
| Radio Dealers Licence | RD-001 | 10 business days |
| Radio Frequency Licence | RF-001 | 45 business days |
| Satellite Service Licence | SS-001 | 60 business days |
| Type Approval Licence | TA-001 | 30 business days |
| VANS Licence | VN-001 | 30 business days |

## How to Use

1. Users download the appropriate form from the application page (Step 2)
2. Forms can be completed digitally using Adobe Acrobat or printed and filled by hand
3. Completed forms must be signed before uploading
4. Forms are uploaded along with supporting documents in Step 3

## Required Supporting Documents

Depending on the license type, applicants may need to upload:

- Completed application form (signed)
- Company registration certificate
- Tax Identification Number (TIN) certificate
- ID copies of directors/owners
- Proof of physical address
- Technical specifications (for equipment-related licenses)
- Business plan (for telecom/broadcasting licenses)
- Financial statements (for major licenses)

## File Format Requirements

- Accepted formats: PDF, JPG, PNG
- Maximum file size: 10MB per file
- All documents must be clearly legible
- Scanned documents should be in color at minimum 300 DPI
